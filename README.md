TimerBall
A 2D game where a ball must reach the finish line while avoiding various obstacles.
In Touch mode, you can touch obstacles and borders without dying; in No Touch mode, touching them results in death.
Every time you die, you have to start all over again from the beginning, and while the early levels are simple, it gets very difficult later on due to invisible barriers and rotating blades.
Reaching level 50 in No Touch mode is almost impossible.
It is still a prototype, so there might be bugs, though I haven't noticed any so far.
